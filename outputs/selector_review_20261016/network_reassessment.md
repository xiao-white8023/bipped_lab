## 当前架构及训练关系

底层 RENet 固定，向 selector 提供可观测特征。冻结底层 RENet 与第二阶段冻结风险预测器是两件不同的事。

```text
5 × 283 可观测历史
       ↓
训练集拟合的同一个特征归一化器
       ├─ 风险 MLP：283 → 256 → 128
       │      ↓ GRU128
       │   风险 hidden128 → head64 → 两个 sigmoid → 仿射校准 → pLP、pVP
       │
       └─ 四分类自己的 MLP：283 → 128 → 64
              ↓ GRU64
           outcome hidden64
              + risk hidden128
              + 校准风险的两个 logits
              ↓ head96、dropout
           四个 logits → 温度与类偏置校准 → softmax q0…q3
```

默认风险网络 213,826 个参数；新增 outcome 网络 89,060 个参数，总计 302,886 个参数。参数数量不能单独证明容量足够或不足。

当前 full 训练第一阶段从随机初始化训练完整风险网络及训练集归一化统计，并拟合风险校准。第二阶段固定本轮风险预测器，训练新的 outcome 编码器、GRU 和输出头。Outcome 自己读取完整历史，不是只能读取风险输出的一个小分类头。

相关源码：`model.py:54`、`outcomes.py:54`、`outcomes.py:99`、`train_selector_full_outcomes.py:18`。

## 两种预测在统计上分别表达什么

令 yLP、yVP 表示固定底层策略在相应分支反事实执行下，未来一秒内是否发生定义的物理失败。标签包含正常五步动作融合，不包含真实运行中的驻留和确认等待。

- 两个 BCE 输出估计边际风险 pLP、pVP；它们不需要假设两路失败相互独立。
- 四分类估计联合结局：q0=双安全、q1=仅 LP 失败、q2=仅 VP 失败、q3=双失败。
- 一致的联合与边际应满足 pLP=q1+q3，pVP=q2+q3。
- 两个边际不能唯一确定 q3，因此不能默认 q3=pLP*pVP。

例如 pLP=pVP=0.5，联合分布既可以是 [0.5,0,0,0.5]，也可以是 [0,0.5,0.5,0]。两种情况下是否存在单路救援机会、双失败告警的含义不同。

四分类任务因此有必要；可精简的是重复的边际预测来源，而不是直接删除联合风险建模。

## 对训练目标的复审

1. 风险加权 BCE 与 outcome 加权 CE 的原始分数通常不是自然分布后验。当前实现已经分别使用验证集无权重损失拟合校准；不能说没有校准。全局温度和偏置仍不能保证故障子群校准，也不能修复排序或信息缺失。
2. outcome 的方向辅助 CE 仅使用真实单失败样本和类别 1/2 的 logits。它强调方向区分，不能直接证明它损害 q0/q3；需做 CE-only 和降低辅助系数的消融。目前 CLI 禁止 coefficient=0，损失函数本身支持零。
3. 方向辅助损失按当前 batch 的单失败子集独立归一化。其相对作用随 batch 组成变化；系数 1 不等同于简单的逐样本同等权重。
4. ShardBatchSampler 按 shard 连续组成 batch。LP 补充的大 shard 可以产生纯类 batch，小 shard 也可能跨来源混合；不能笼统说所有 batch 均为纯类。weighted CE 默认按 batch 目标权重总和归一化，纯类 batch 中类别权重抵消，数据包装影响有效权重。应先明确混批和固定归一化方式。
5. 风险训练的 sigmoid→clamp→log BCE 在极端错误饱和输入下可能产生零梯度；BCEWithLogits 可改善数值稳定性，但目前没有证据表明这是实际主要病因。

## 值得测试的监督学习简化

建议将当前两阶段模型保留为对照，测试一套时序编码器输出四分类 q，并始终从校准后的 q 求和得到边际风险：

```text
5 × 283 → MLP + GRU → 四类 q
                         ├→ pLP = q1 + q3
                         ├→ pVP = q2 + q3
                         └→ q3 作为双失败风险
```

可从 joint CE 基线开始，再比较边际 BCE 辅助监督：

L = CE(q, joint_label) + λ × [BCE(q1+q3,yLP) + BCE(q2+q3,yVP)]。

在同一数据分布、无权重时，这些目标指向一致的真实联合后验。数据重采样和类别加权另行声明，校准后不再单独校准边际以免破坏一致性。统一模型的优点是概率一致、训练和部署接口简单；是否性能提升必须对照验证，不能预先保证。

## 决策应读取的两个不同量

g=q1+q2 表示恰好一路失败、另一路安全的概率；d=q1/(q1+q2) 表示在单路失败条件下偏向 LP 失败的程度。

旧 V5 validation 上 g 对真实单路失败事件的 AUROC=0.975155，ECE=0.001561；d 在真实单路失败子集中的 AUROC=0.995513。两个指标的评价样本范围和目标不同，不能把差值当作同一任务上的性能差。

当前 log(q1/q2)=logit(d)，其比率本身不包含 g。即使条件方向明确，g 仍可能很小。当前规则还带有最低救援概率及 q0/q3 保持门，因此不能说完全没有绝对概率检查；应核查这些门是否有效，而不是只优化方向排名。

模型评价应同时覆盖四类 NLL/Brier/分离度、由 q 求和得到的边际风险、单失败方向区分、告警精确率召回，以及固定决策下的救援与有害切换。旧 validation 的高 AUROC/ECE 不能替代独立新故障测试与真实状态机闭环验证。

本次复审不支持“监督学习必须放弃、立即改 PPO”的结论。先分开验证预测、概率一致性、训练目标及动作规则，才能决定是否需要更换学习路线。
